# 去AI味写作指南

## 一、核心原则：像人，不像模板

### AI写作的典型问题：
- 开头总喜欢"在...的世界里"或"阳光洒在..."
- 结尾强行升华、点题、总结人生哲理
- 人物性格扁平，行为逻辑模板化
- 对话像教科书，缺乏口语感和个性
- 情感描写空泛，堆砌形容词
- 过度使用排比、对仗、三段式
- 每段长度相近，结构太工整
- 破折号、省略号滥用
- 结尾喜欢用"原来..."、"那一刻，他终于明白了..."

### 人写作的特点：
- 开头可能突然、随意，像从中间切入
- 结尾可能开放、模糊、不圆满
- 人物有矛盾、有缺陷、有不可预测性
- 对话有口语、有打断、有言外之意
- 情感通过细节和行为呈现，而非直说
- 句子长短不一，节奏自然
- 有废话、有留白、有不完美
- 有作者的个人视角和偏见

## 二、AI高频禁用词

### 抽象升华词
命运、宿命、注定 → 用具体事件代替抽象概念

### 文艺比喻词
仿佛、宛如、犹如、似乎、好像 → 直接描写，少用比喻

### 时间标记词
这一刻、这一瞬间、刹那间 → 用动作或对话推进，不要标记时间

### 情绪总结词
心中涌起、不禁感慨、莫名感动、不由得 → 用具体反应代替情绪总结

### 总结转折词
然而、不过、可是 → 短句直接转折，不要用连词铺路

### 评价性描述
深深地、缓缓地、轻轻地 → 删掉副词，用动作本身传达

### 万能比喻
像潮水般、如闪电般、仿佛春风 → 要么不用比喻，要么用生活化的比喻

## 三、核心写作规则

### 规则 1：段落不超过 3 句
错：他看着窗外的雨，心中涌起一股说不清的感觉。这些年走过的路，经历的种种，都在这一刻涌上心头。他想起了那个夏天，想起了那个人的笑容，想起了很多以为自己已经忘记的事。

对：他盯着窗外。雨下了很久。
"你还在想她？"老刘问。
他没说话。

### 规则 2：动作 + 对话 + 情绪反应
三要素循环推进，不要单写心理活动超过 2 段。
情绪不用"他感到/他觉得"，用身体反应和行为表现：
- 不写"他很紧张" → 写"手心全是汗，筷子差点掉了"
- 不写"她很愤怒" → 写"她把杯子摔在地上，碎片弹到脚背上也没弯腰捡"
- 不写"他很伤心" → 写"他在车里坐了二十分钟才发动引擎"

### 规则 3：短句优先
- 打斗/紧张场景：3-8字（他侧身。刀光一闪。血溅在墙上。）
- 对话：口语化（"你疯了？""可能吧。"）
- 日常：8-15字（厨房里有炒菜的声音，闻着像辣椒炒肉。）
- 描写：不超过20字（天快黑了，巷子里没什么人。）

### 规则 4：口语化表达
- 允许用俚语、粗话（符合角色身份）
- 对话不要书面语（"我认为此事不妥" → "我觉得不靠谱"）
- 叙述也不要端着（"他目光如炬" → "他眼珠子一动不动盯着"）
- 短语优先于成语（"无可奈何" → "没办法"）

## 四、Show Don't Tell 原则

| Tell（告诉） | Show（展示） |
|-------------|-------------|
| 他是个胆小的人 | 他把检查报告在手里翻来覆去看了三遍，还是不敢打开 |
| 这间酒吧很吵 | 酒保凑到他耳边喊了两次他才听见 |
| 她很富有 | 她随手把一张信用卡丢在桌上，卡面上的数字比这顿饭贵十倍 |
| 两人关系很差 | 他把烟掐灭在她刚泡的茶杯里，她面无表情地把杯子推到一边 |
| 他很聪明 | 三秒钟。他看了三秒钟就把文件合上了。"第三页，第二行。" |

## 五、章末总结体禁令

**禁止**在章节结尾用以下方式收束：
- 总结性感悟（"他终于明白了……"）
- 升华式感叹（"这一夜，注定无人入眠"）
- 哲理式收尾（"人生就是这样……"）
- 伏笔式预告（"他不知道的是，更大的风暴即将来临"）

**正确做法**：章尾用动作、对话或悬念收束，让情节本身制造余韵。

## 六、语言细节清单

### 句式变化
- 长短句交替，避免都是中等长度
- 偶尔用短句制造冲击力
- 允许句子不完整（口语感）
- 避免每个句子都很"完整"和"工整"

### 词汇选择
- 少用书面语：摒弃、亦、乃至、所谓
- 多用口语：算了、罢了、也是、就说
- 具体词代替抽象词：用"烟灰缸满了"代替"时间流逝"
- 动词优先于形容词

### 标点使用
- 少用破折号（——）
- 少用省略号（......）
- 多用句号，让句子更短
- 对话可以没有引号，用分行表示

### 段落节奏
- 长短段落交替
- 偶尔单句成段
- 避免每段都是3-5句

## 七、人物塑造

### 不要做
- 给人物贴标签（善良、勇敢、聪明）
- 人物行为完全符合其"设定"
- 让人物说出自己的人设
- 所有人物说话方式相同

### 要做
- 让人物有矛盾（嘴硬心软、表面洒脱内心纠结）
- 让人物有缺点（小气、八卦、懒惰、虚伪）
- 让人物行为有意外（好人做坏事，坏人动恻隐）
- 每个人有独特的说话方式

## 八、场景描写

**不好（堆砌形容词）：**
破旧的房间里弥漫着陈旧的气息，昏暗的灯光下，斑驳的墙壁诉说着岁月的沧桑。

**好（具体细节）：**
房间里的灯泡瓦数太小，墙皮起鼓，像要掉不掉的样子。

## 九、情感表达

**不好（直白说出）：**
他感到一阵莫名的悲伤，内心涌起一股难以言喻的孤独。

**好（通过行为暗示）：**
他点了支烟，没抽，就让它烧着。烟灰掉在裤子上，他也没管。

## 十、快速自检口诀

一段不过三句话。
对话要像人说话。
心情不写心里话。
结尾不搞大升华。
打斗不写流水账。
日常要埋伏笔桩。

## 十一、正确替代示例

| 错误表达 | 正确表达 |
|---------|---------|
| 他感到一丝紧张 | 他的手在抖 |
| 她很伤心 | 她转过身去，肩膀微微颤动 |
| "好的。"他说道 | "好的。"他点了根烟 |
| 他深吸一口气 | 他把烟摁灭在烟灰缸里 |

## 十二、去AI三遍法

### Pass 1：去泛化
- 抽象情绪总结句 → 删或替换为具体动作
- 假深度句（"生活就像一场戏"）→ 删
- 意义膨胀 → 缩小到具体影响
- 空洞结论 → 删
- 工整对比句式 → 打散重写
- 装饰性形容词堆砌 → 白描

### Pass 2：去书面化
- 分析性用词（机制、结构、逻辑）→ 换成日常表达
- 抽象名词滥用 → 直接说事
- 体制内用语 → 删
- 专业术语堆砌 → 只保留必要的，用白话解释

### Pass 3：回人味
- 添加具体的感官细节（气味、温度、触感）
- 区分角色说话方式
- 添加微小的不完美（口语化表达、小错误）
- 加入个人视角和偏见
