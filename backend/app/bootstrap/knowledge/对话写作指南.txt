# 对话写作指南

## 核心原则

每句对话必须完成以下至少一项：
1. 推进剧情
2. 暴露角色性格
3. 改变关系压力
4. 隐藏什么（言不由衷）
5. 间接揭示信息

做不到以上任何一项的对话 = 删。

---

## 潜台词技法

### 话题偏移
回答问题时故意跑题。
- "你昨晚去哪了？" → "今天天气不错。"

### 反问回避
用问题回答问题。
- "你是不是喜欢他？" → "你为什么这么关心？"

### 说别的事
通过谈别的传递信息。
- （实际在说分手）"你看见楼下那家店关了吗？开了三年了。"

### 沉默与动作
不回答就是回答。
- "你还爱他吗？" / 她没说话。把杯子放下了。

### 听到更多
无意中听到的话比当面说更有力。
- 门外："她不知道吧？" / "不知道。别告诉她。"

## 对话节奏

### 快节奏（冲突/争吵）
- 短句，15字以内
- 不用对话标签（"他说"）
- 允许打断
- 不用描写穿插

```
"你疯了。"
"我疯了？你看看你自己。"
"别转移话题。"
"什么话题？你今天又喝了吧。"
```

### 慢节奏（暧昧/深聊）
- 长句，允许停顿
- 用动作和环境做呼吸
- 话题可以绕弯

```
"你还在想那件事？"
她没回答。窗外的梧桐树被风吹得哗哗响，有几片叶子飘到了阳台上。
"有时候，"她终于开口，"我觉得自己一直在等一个不会来的人。"
```

## 权力动态

对话中的权力关系通过以下信号体现：

| 维度 | 高位者 | 低位者 |
|------|--------|--------|
| 谁提问 | 多问少答 | 多答少问 |
| 谁打断 | 随时打断 | 不敢打断 |
| 谁控题 | 控制话题方向 | 跟随话题 |
| 谁沉默 | 用沉默施压 | 用沉默逃避 |
| 句子长度 | 短，果断 | 长，解释多 |
| 直接程度 | 直说 | 绕弯 |

## 角色语气区分

### 6种核心说话类型

| 类型 | 特征 | 示例 |
|------|------|------|
| 防御幽默型 | 用笑话保护自己 | "没什么，就是手抖了一下。最近咖啡喝多了。" |
| 直球暴力型 | 不拐弯抹角 | "滚。" |
| 过度控制型 | 话说得很完整，像在做报告 | "根据目前的情况来看，我建议我们分两步走。" |
| 自我取消型 | 先说了又收回去 | "我其实……算了，没什么。" |
| 道德绑架型 | 用道理压人 | "你这样做对得起谁？" |
| 柔性诱惑型 | 声音轻，话里有余地 | "你确定？你再想想？" |

### 操作规则
- 一个角色最多用1-2种类型
- 不要给每个角色加口头禅（太假）
- 语气来自社会位置和性格，不是"标签"

## 沉默也是对话

| 沉默类型 | 含义 |
|----------|------|
| 抗拒的沉默 | 不想回答，拒绝配合 |
| 羞辱的沉默 | 让对方意识到自己说了蠢话 |
| 算计的沉默 | 在想怎么回答最有利 |
| 吸引的沉默 | 不说话就是在调情 |
| 恐惧的沉默 | 不敢说 |
| 权力的沉默 | 让你等，让你急 |

---

## 对话禁忌

| 禁忌 | 说明 |
|------|------|
| 所有人说话一个味 | 没有区分度 |
| 每句都有"他说""她说" | 用动作替代标签 |
| 角色把自己的动机说清楚 | 真人不会解释自己 |
| 信息量过大的对话 | 一句话交代太多背景 |
| 连续对话超过15轮没有动作/描写 | 读者会飘 |
| 对话中大量感叹号 | 降低情绪密度 |

---

## 对话情绪五级递增

| 等级 | 类型 | 示例 | 情绪强度 |
|------|------|------|----------|
| 1 | 客观陈述事实 | "你迟到了两个小时。" | 最弱 |
| 2 | 客观陈述 + 提出建议 | "你迟到了，下次能不能提前说一声？" | 礼貌但有力 |
| 3 | 主观指责 | "你永远只考虑自己。" | 开始冲突 |
| 4 | 主观指责 + 强制命令 | "你就是这样的人。现在给我出去。" | 强情绪 |
| 5 | 主观指责 + PUA抬升自己 | "我是为你好才忍你这么久，你看看你自己配不配。" | 最强 |

## 对话信息控制

### 对话中留悬念
- 对话不必讲清楚前因后果，留悬念
- 读者会自己脑补，联系前后文
- 用到哪个设定稍微带出来就行

### 对话占篇幅太多的解决方案
1. **大量信息用对话展示？** → 转化为情节、心理描写、旁白、环境、动作
2. **一问一答式对话？** → 改为"一个人主动说，另一个人给予评价等反应"
3. **依赖对话推动剧情？** → 用突发小状况代替对话

### 潜台词写作法
1. 在对话旁边先写出潜台词内容
2. 对照潜台词写出正式对话
3. 删掉潜台词部分
4. 检查：读者能否通过上下文读出潜台词

## 对话标签写法

| 标签类型 | 使用频率 | 范例 |
|----------|----------|------|
| 无标签（纯对话） | 60%+ | 直接换行写对话 |
| 动作标签 | 25% | 她端起酒杯，仰头一口闷了。"……" |
| 神态标签 | 10% | 他眯起眼。"……" |
| "XX说/道" | <5% | 极少使用 |

## 情绪对话写法

### 愤怒
- 短句、粗口（适度）、感叹号、打断对方
- 示例："你他妈少看不起人！"

### 悲伤
- 省略号、"求"、声音描写、短句
- 示例："求你了，让我走吧……"

### 嘲讽
- 冷、短、不带感情、用行动回应
- 示例："那就来吧。"

### 震惊
- 单字、反应先于语言、声音/表情描写
- 示例："你！"她气得直接笑了出来。

### 调情/暧昧
- 直接、挑逗、用身体语言配合
- 示例："亲我。"

### 威胁
- 具体行动 + 后果、不给缓冲
- 示例："如果不答应，我现在就吞了这瓶安眠药。"
