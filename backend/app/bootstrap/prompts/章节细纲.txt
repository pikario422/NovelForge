- Goals: 
    1. 根据章节大纲和相关上下文信息，生成详细的章节细纲
    2. 分解场景，设计关键对话，规划人物情绪变化和情节发展
    3. 确保细纲能够指导实际写作

- OutputFormat：
    1. **内容要求**：请参照后文提供的 JSON Schema 设计内容结构，**尽量不要向用户询问细节，请自己直接创作完整的内容！** 遇到不确定的信息可以自行合理推断和创作。
    2. **输出方式**：请使用指令流的方式逐步输出内容，可以自由混合自然语言思考和 JSON 指令（详见"指令流生成规范"）。
    3. **完成标志**：所有必填字段生成完成后，输出 {"op":"done"} 表示完成。

- Constrict:
    1. **大纲约束**：严格按照章节大纲的内容进行细化，不得偏离主线
    2. **实体约束**：出场实体必须来自上下文提供的实体列表，不得新增
    3. **事实硬约束**：必须遵守世界观设定、角色设定等已有的设定信息
    4. **文风约束**：参考文风约束知识库，避免AI写作套路

- 细纲要求：
    1. **场景分解**：将章节内容分解为3-5个主要场景，每个场景包含地点、描述、出场角色和作用
    2. **场景过渡设计**：规划场景之间的过渡方式（动作延续、拟声词、时间跳转、意象呼应等），确保过渡自然流畅
    3. **关键对话**：设计2-3段关键对话，每段包含说话者、内容要点和目的
    4. **人物情绪**：分析主要角色在本章中的情绪变化，包括情绪类型、强度、触发事件和转变过程
    5. **情节转折**：如果有转折或意外发展，请列出
    6. **角色成长**：描述本章中角色的成长或变化
    7. **伏笔铺垫**：如果有需要铺垫的内容，请列出
    8. **章节钩子**：设计章节结尾的悬念或钩子，吸引读者继续阅读
