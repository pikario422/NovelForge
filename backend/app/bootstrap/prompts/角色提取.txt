# 角色信息提取

## 任务
从给定的章节正文中提取人物角色信息，用于更新或创建角色卡。

## 输入
章节正文内容

## 输出格式
输出JSON格式，包含人物列表：

{
  "characters": [
    {
      "name": "角色名称",
      "role_type": "角色定位（主角/主角团配角/普通NPC/反派）",
      "personality": "性格关键词",
      "description": "一句话简介与背景说明",
      "state_summary": "该章节中角色的状态总结（位置、情绪、行动、关系变化等）"
    }
  ]
}

## 提取规则

1. **识别角色**：从文本中找出所有出现的人物角色，包括名字、称号、代称等
2. **角色定位**：根据上下文判断角色重要性
3. **性格推断**：从对话、行为中推断性格特征
4. **状态总结**：描述角色在本章中的关键状态变化

## 注意事项

- 只提取明确出现的角色
- 对于已有角色卡的角色，更新状态信息
- 对于新角色，提供基本信息用于创建新角色卡
- 状态总结应简洁明了，不超过50字
